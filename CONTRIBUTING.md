# How this team works

**One question, one Issue.** Questions go in Issues, not the group chat.
Title = the question. Close it with the answer in the thread.

**Status tags.** Every number in a model card carries one tag:
`[verified]` a second member recomputed it and it matched;
`[computed]` one member computed it, unchecked;
`[copied]` taken from a lecture/workbook, with the source named;
`[assumed]` a choice, with one sentence of justification.
A model card with untagged numbers is not done. (Convention borrowed from
scholarhaozheng/mobility-network-lab - per-record status, no aggregate claims.)

**data/ is frozen.** Nothing in `data/` is ever edited. Derived files go in
`derived/`, model cards in `cards/`, figures in `fig/`.

**Hours.** Each member logs tasks + hours + an evidence link (commit, file +
sheet, or Issue number) in `log/Team_Contribution_Log.xlsx`. The leader
confirms rows they have actually seen. The log is a required attachment at
M1 and M2.

**Commits.** Commit your own work under your own GitHub account - the commit
history is the evidence column of the hours log.

**Visibility.** This repo is private. Nothing leaves it until Dr. Zhou approves.
